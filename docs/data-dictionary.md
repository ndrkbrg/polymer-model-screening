# Computational data dictionary

`docs/DATASET_INDEX.json` lists each CSV with its row count and exact ordered fields. `docs/COLUMN_INDEX.json` maps each field to all files containing it. UTF-8 CSV uses comma separators and dot decimals. Empty fields denote an inapplicable experiment condition or an unavailable value; they are not zeros. Preserve status fields and finite-value counts. All data are simulated or derived. Model families `PAA` and `NVPVPE` are effective parameterizations, not measured specimens.

## Identifiers, conditions and raw metrics

| Fields | Meaning and units/convention |
| --- | --- |
| `system`, `model`, `condition`, `group`, `response`, `topology`, `experiment`, `benchmark`, `constraint`, `route`, `setting`, `representation` | Categorical labels defined by the corresponding experiment runner and effective config. They define grouping, not replicates. |
| `seed`, `narma10_task_seed`, `geometry_seed`, `noise_seed`, `memory_seed` | Integer random seeds. Revision seed offsets are explicit in `run_revision_phase_c.py`; original seeds and transformations are in the corresponding original runner. |
| `N`, `size`, `rank_target`, `levels`, `alphabet_size` | Unit/component count, Bars-and-Stripes side length, target rank, quantization levels, or state-alphabet count respectively. `levels=0` denotes no quantization where used. |
| `spread`, `radius`, `a`, `noise`, `tau`, `gain`, `response_width`, `input_scale`, `driven_fraction` | Effective model/control values. `radius` is the normalized spectral radius; revision `a` is the response-potential coefficient; `noise` is D in the integrator; `tau` is a relative relaxation scale. `driven_fraction` is the fraction of driven units. These are reduced numerical scales, not independently calibrated physical units. See config and physical parameter table. |
| `threshold_fraction`, `corruption`, `perturbation`, `cutoff`, `error`, `update_noise`, `mem_gamma`, `mem_dep_ratio` | Threshold relative to local-field scale; cue bit-flip fraction; normalized coupling perturbation; residual decision cutoff; route-specific one-time weight error; update noise and memristor-law parameters. Definitions differ by experiment; no common hardware noise scale is implied. |
| `field_scale`, `value` | Local-field normalization used for attractor thresholds; tested value whose meaning is given by `experiment`. Neither is a measured SI field. |
| `budget`, `validation_starts`, `top_k`, `bank`, `start`, `target`, `repeat` | Discovery-start budget; held-out starts; retained attractor count (`top_k=0` means all discovered); bank label; start index; serialized discrete target; cue-repeat index. Discovery and validation banks are separate. |
| `n_attractors`, `observed_attractors`, `new_attractors`, `n_targets`, `n_cues`, `stable_state_count`, `nonconverged_starts`, `fields_tested` | Integer counts within the indicated experiment/seed/budget. More starts do not prove exhaustive discovery. |
| `perfect_recall_rate`, `perfect`, `weighted_recovery`, `mean_overlap`, `overlap`, `target_fixed` | Exact-target recovery fraction/indicator; basin-weighted recovery; spin-overlap with the target; target remains fixed indicator/fraction. Recovery is of native attractors, not a trained arbitrary-pattern capacity. |
| `convergence_rate`, `cycle_rate`, `timeout_rate`, `discovery_convergence` | Fractions of starts/cues ending at a fixed point, in a detected cycle, or at the sweep limit. Discovery convergence refers to its discovery bank. |
| `mean_sweeps`, `sweeps`, `washout`, `n_train`, `n_test`, `delay` | Update sweeps or discrete time-sample counts, not seconds. Chronological train/test sample counts are explicit in revision reservoir rows. |
| `retained_discovery_fraction`, `validation_known_fraction`, `validation_selected_fraction` | Fraction of discovery-bank starts represented by retained targets; validation starts reaching any discovered target; validation starts reaching selected retained targets. Nonconverged starts remain in the relevant denominator. |
| `symmetrizability_error`, `symmetry_residual`, `weighted_energy_violations`, `ordinary_energy_violations`, `exact_break`, `practical_break`, `exceeds` | Relative diagonal-symmetry residual; counts of energy increases; Boolean flags for numerical/practical thresholds. `exceeds` means residual exceeds the declared `cutoff`. These are diagnostics, not universal physical transitions. |
| `narma10_nrmse`, `narma20_nrmse`, `mackey_glass_nrmse`, `nrmse_train` | Root-mean-square prediction error divided by target standard deviation on the stated held-out task or training segment. Dimensionless; lower is better. |
| `r2`, `memory_capacity` | Per-delay squared correlation and its sum across tested delays (40 in revision). Dimensionless. The implementation's delay-specific finite-value conventions are in `reservoir/metrics.py`. |
| `esp_max_distance`, `has_esp` | Finite-horizon state-distance diagnostic and tolerance-based flag. They do not prove the global echo-state property. |
| `basin_entropy`, `top_basin_fraction`, `addressability_score`, `best_field_kind`, `best_field_fraction`, `transition_success_rate`, `nontrivial_transition_found`, `increment_found` | Basin Shannon entropy (natural-log units), largest basin fraction, addressability/control results, selected field label/scale, transition fraction and Boolean findings. See `run_phase4_multivalued_q1.py` for exact finite-control protocol. These do not establish a full logic instruction set. |
| `valid_fraction`, `mode_coverage`, `duplicate_rate` | Fraction of generated samples in the target Bars-and-Stripes set; distinct valid target modes observed divided by all target modes; repeated-sample fraction. Dimensionless. |
| `negative_log_likelihood`, `kl_target_to_model` | Exact target-set NLL and KL divergence using natural logarithms (nats). Joint validity and coverage must also be examined. |
| `mixing_time` | Saved finite-chain activity-autocorrelation diagnostic in samples; not a demonstrated global mixing time. |
| `negative_residual`, `local_residual`, `rank_residual`, `approximate_intersection` | Constraint-projection residuals and approximate-intersection flag. Nonnegative/local/low-rank constraints are generic RBM abstractions. |
| `status`, `task_status`, `memory_status` | Explicit success, fixed/cycle/timeout or failure diagnostic. A nonempty error is not silently treated as a successful zero score. |
| `matrix_sha256`, `input_sha256`, `input_weights_sha256` | SHA-256 of little-endian float64 arrays in revision `array_hash`; used to verify paired controls share the specified data or matrix. |

## Derived tables

Original summaries use grouping fields plus `metric`, `n`, `mean`, `std`, `median`, `ci95_low`, `ci95_high`. Standard deviation uses ddof=1 (0 for a singleton). Percentile bootstrap is deterministic with 10,000 resamples for the full saved suite; its seed is `20260706 + sum(ord(character) for character in metric)`. Revision summaries additionally retain `n_total`, `failed_or_missing`, `minimum`, `maximum`, and use bootstrap seed 20261020. Intervals are pointwise, not simultaneous.

Contrast columns identify the paired conditions, metric, family, pair count, mean/median difference, CI and Wilcoxon statistic/p-values. The revision difference is treatment minus the named reference; inspect `comparison` and analysis function `contrasts` before interpreting direction. `p_holm` applies to the explicitly declared family of 16 primary tests; secondary contrasts remain exploratory. `paired_differences_raw.csv` retains each paired `difference`. Original comparisons use `condition_a` minus `condition_b`, report `mean_paired_difference`, `wilcoxon_statistic`, and unadjusted `p_value`, and adjust across their separate eight-test family; do not pool their p-values with revision tests.

Figure source CSVs select or reshape the corresponding summary columns; their grouping labels and statistic fields retain the definitions above. The multivalued confusion table records `field_kind`, `field_fraction`, `origin_state`, `target_state`, transition `count` and trial count `repeats` as emitted by `run_phase4_multivalued_q1.py`; state indices are categorical identifiers. The claim mapping uses `id`, `claim`, `evidence`, `location`, `limit`, `evidence_class` and `human_verification` as textual audit fields, not additional observations. The physical-parameter CSV uses `symbol`, `meaning`, `unit`, `source`, `rationale`, `sensitivity_or_limit`, `calibration` and `manuscript_location` as model-specification fields, rather than declaring every parameter experimentally measured.

## Checkpoint arrays

Each revision checkpoint JSON stores the seed job's raw records. Reservoir `.npz` keys are `native`, `symmetric`, `shuffled`, `random` (40-by-40 normalized matrices), `raw_J` (unscaled coupling), `input`, `target`, `memory_input`, `input_weights`, and condition-specific `_prediction` arrays for the held-out segment. Attractor `.npz` keys are `W`, `noise_direction` (30-by-30 arrays), `source` and `receiver` (30-element vectors). These preserve within-seed pairing and audit CSV results. Array shapes and exact keys can be inspected with `numpy.load(path, allow_pickle=False)`. A hash identifies contents, not physical validation. The runner source and frozen configuration define array generation and chronological slicing. Original per-seed checkpoint arrays were not recovered; original raw records, effective config and source are supplied with that limitation.
